# 分诊标签

各个技能用五个标准分诊角色来描述状态。本文件把这些角色对应到本仓库 issue tracker 里实际使用的标签名。

| mattpocock/skills 中的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info` | `needs-info` | 等待报告人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整说明，可以直接交给无人值守的 agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某个角色时（比如“打上可交给 agent 的分诊标签”），使用上表中对应的标签名。

如果实际用的是别的名称，改“本仓库的标签”这一列即可。
