# 阶段 2 人工验收清单

准备：

- 手机测试需要 HTTPS，先按 [docs/dev-https.md](../dev-https.md) 配好 Caddy 和根证书。
- 用构建好的二进制：`scripts/build.sh` 后运行 `bin/lode serve`。开发模式下没有 Service Worker。
- 下文“电脑”指电脑浏览器访问 `https://<局域网IP>:8443`（也可以用 `http://127.0.0.1:8787`）。

- [ ] **1. Android Chrome：安装到主屏、断网编辑、联网同步**
  - 操作：
    1. Chrome 打开 Lode 并登录，菜单 → “安装应用”（或“添加到主屏幕”）。
    2. 从主屏图标启动，打开两篇笔记各看一眼（正文会缓存到本机）。
    3. 打开飞行模式，彻底关掉 Lode 再从主屏启动。
    4. 编辑刚才那两篇笔记。
    5. 关闭飞行模式。
  - 预期：
    - 主屏图标是蓝底白色 L，启动后没有浏览器地址栏。
    - 断网冷启动能看到文件树，打开过的笔记可以编辑。
    - 侧栏底部显示“离线（2 项待同步）”。
    - 联网后几秒内变成“已同步”，电脑上不刷新就能看到这两处修改。
  - 用户反馈：

- [ ] **2. iOS Safari：添加到主屏、图标与状态栏、断网编辑**
  - 操作：
    1. Safari 打开 Lode 并登录，分享 → “添加到主屏幕”。
    2. 从主屏启动，重复第 1 项的第 2–5 步。
  - 预期：
    - 添加时预览图标是蓝底白色 L，不是网页截图；名称默认为“Lode”。
    - 启动后全屏显示，顶部状态栏文字清晰可见，不遮挡标题栏。
    - 断网、联网后的表现与第 1 项相同。
  - 用户反馈：

- [ ] **3. 两台设备同时编辑同一篇：不同段落自动合并**
  - 操作：电脑和手机打开同一篇有三段文字的笔记。手机开飞行模式后改第三段，电脑改第一段，然后手机联网。
  - 预期：
    - 两端最终都同时包含两处修改，不生成冲突副本，也不弹冲突提示。
    - 手机上的光标位置保持不动，不跳到开头。
    - 在线时两端轮流改不同段落：对方的修改约 2 秒内出现，自己正在输入的内容不丢失、不被打断。
  - 用户反馈：

- [ ] **4. 两台设备同时编辑同一篇：同一行冲突**
  - 操作：手机开飞行模式后改某一行，电脑改同一行，然后手机联网。
  - 预期：
    - 手机提示“…与其他设备的修改冲突，你的版本已另存为冲突副本”。点“打开副本”能看到自己的版本。手机上原笔记换成电脑的版本。
    - 电脑提示“…在另一台设备上与你的修改冲突，已生成冲突副本”。点“查看副本”可以打开。
    - 两端侧栏底部都显示“有冲突”。点它会列出冲突副本，点某一项打开该副本，状态随之恢复。
    - 文件树里出现 `名称.conflict-<设备名>-<日期-时间>`，设备名是手机的。
  - 用户反馈：

- [ ] **5. 修改设备名**
  - 操作：点侧栏底部的同步状态 → “本机设备名：…”，改成“我的手机”，再按第 4 项制造一次冲突。
  - 预期：输入框默认值是从浏览器推断出的名称（例如“Android Chrome”）。改名后新生成的冲突副本文件名里是“我的手机”。刷新后设备名保持不变。
  - 用户反馈：

- [ ] **6. 真实中文输入法下接收远端修改**
  - 操作：手机（或电脑）用中文输入法在笔记里打拼音，组字过程中不上屏、停留几秒。这时另一台设备修改同一篇的其他段落。然后选字上屏。
  - 预期：组字期间候选框不消失、拼音不被替换。上屏后另一台设备的修改出现，刚上屏的字也在，两端最终一致。
  - 用户反馈：

- [ ] **7. “有新版本，点击刷新”提示**
  - 操作：手机从主屏打开应用，然后切到别的应用。在电脑上随便改一处前端文字，重新执行 `scripts/build.sh` 并重启 `bin/lode serve`。切回 Lode（不刷新）；再在电脑浏览器里刷新一次页面。
  - 预期：底部出现常驻提示“有新版本，点击刷新”，带“刷新”按钮和关闭按钮。点“刷新”后页面重新载入，显示新版本。点关闭则提示消失，不自动刷新。
  - 用户反馈：

- [ ] **8. 外部编辑器修改打开中的笔记（阶段 1 第 7 项的新行为）**
  - 操作：在 Lode 中打开一篇笔记，用 VS Code 修改 vault 里的同一个文件并保存。先在 Lode 没有修改时做一次，再在 Lode 刚输入、还没保存时做一次。
  - 预期：没有本地修改时，约 1–2 秒内正文更新，光标保留。有本地修改时，不再出现提示条，Lode 会立即保存并由服务器合并：
    - 改的不是同一处：两边的修改都保留；
    - 改了同一行：服务器保留外部版本，Lode 的版本另存为冲突副本并弹出提示。
  - 用户反馈：
