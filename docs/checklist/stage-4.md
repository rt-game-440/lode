# 阶段 4 人工验收清单

准备：

- 用构建好的二进制：`scripts/build.sh` 后运行 `bin/lode serve`。
- 经 HTTPS 访问需要先按 [docs/dev-https.md](../dev-https.md) 配好 Caddy；只在本机验收时用 `http://127.0.0.1:8787` 即可。
- 接入写法见 [docs/mcp.md](../mcp.md)。

- [x] **1. 用自己的 Claude Code 接入，日常使用一次**
  - 操作：
    1. 设置页创建读写 token，名称填 `Claude Code`，点接入命令旁的复制按钮。
    2. 在终端粘贴运行，然后运行 `claude mcp list`。
    3. 在 Claude Code 里提一个真实的需求，例如“把今天的会议要点追加到某篇笔记末尾”，或“找出所有带 #待办 的笔记并汇总”。
    4. 同时在浏览器（或手机）里打开那篇笔记。
  - 预期：
    - `claude mcp list` 显示 `lode … ✔ Connected`。
    - Claude Code 能找到笔记并完成修改，打开着的页面不刷新就出现修改。
    - 设置页“调用记录”里能看到这几次调用，token 列表的“最后使用”时间已更新。
  - 用户反馈：通过（2026-11-08）

- [x] **2. 只读 token 与吊销**
  - 操作：
    1. 再创建一个只读 token，按同样方式接入另一个名称（例如 `lode-ro`），让 agent 修改一篇笔记。
    2. 在设置页吊销这个只读 token，再让 agent 搜索笔记。
  - 预期：
    - 第 1 步 agent 看不到修改类工具，会说明没有写权限，笔记不变。
    - 第 2 步连接失败（401），agent 无法再读取笔记。
  - 用户反馈：通过（2026-11-08）

- [x] **3. 手机上管理 token**
  - 操作：
    1. 手机浏览器打开 Lode，进入侧栏底部的“设置”。
    2. 创建一个 token，点复制，粘贴到备忘录里看一眼，然后点“我已保存”。
    3. 往下滚动查看调用记录，再吊销刚建的 token。
  - 预期：
    - 页面在手机上排版正常，没有横向滚动；调用记录显示为一条条卡片。
    - 复制成功并有提示，粘贴出的是完整 token。
    - 吊销前有确认框，确认后 token 从列表中消失。
  - 用户反馈：通过（2026-11-08）
