# 阶段 1 人工验收清单

启动方式：`scripts/build.sh` 构建后运行 `bin/lode serve`（或 `scripts/dev.sh` 开发模式），浏览器打开 http://127.0.0.1:8787 。

- [ ] **1. 编辑手感（实时预览）**
  - 操作：新建一篇笔记，依次输入标题（`# `）、加粗、斜体、行内代码、列表、任务列表、引用、代码块、分隔线和 `[[链接]]`；光标在各行之间来回移动。
  - 预期：光标所在行显示 Markdown 标记，离开后标记隐藏并显示渲染效果；行高和字号切换时没有明显跳动；任务列表的复选框可以直接点击切换。
  - 用户反馈：

- [ ] **2. 中文输入法下的自动保存**
  - 操作：用系统中文输入法连续输入一段中文，拼音组字过程中停顿超过 1 秒，再上屏。
  - 预期：组字过程中不会保存或打断输入，候选框不闪烁、不丢字；上屏后约 0.5 秒右上角显示"已保存"；刷新后内容一致。
  - 用户反馈：

- [ ] **3. `[[` 补全与链接跳转**
  - 操作：输入 `[[` 后键入笔记名的一部分，用方向键和回车选择；再把光标移开，点击该链接；按住 Ctrl 点击编辑中的链接。
  - 预期：输入 `[[` 自动补上 `]]`；候选按标题模糊匹配；选中后光标落在 `]]` 之后；预览状态单击即可跳转，编辑状态需按 Ctrl/Cmd；目标不存在的链接显示为虚线样式，点击后自动创建该笔记。
  - 用户反馈：

- [ ] **4. 粘贴和拖入图片**
  - 操作：截图后在笔记里 Ctrl+V；再从文件管理器拖一张图片到正文中间。
  - 预期：插入 `![[attachments/…]]` 并在离开该行后显示图片；文件出现在 vault 的 `attachments/` 目录。
  - 用户反馈：

- [ ] **5. 文件树拖放与右键菜单**
  - 操作：把一篇笔记拖到另一个文件夹，再拖回根目录；右键笔记和文件夹，分别试重命名、新建、删除。
  - 预期：拖动时目标文件夹高亮，放下后移动生效；重命名后其他笔记里的链接同步更新（出现"已更新 N 篇笔记中的链接"提示）；删除文件夹前有确认。
  - 用户反馈：

- [ ] **6. 手机端操作**
  - 操作：手机浏览器访问（同一局域网需用 `LODE_ADDR=0.0.0.0:8787` 启动），浏览列表、打开笔记、编辑、返回；长按文件树中的条目。
  - 预期：列表 → 详情的滑入滑出动画流畅、方向一致；长按弹出操作菜单；软键盘弹出时正文不被遮挡；标题栏按钮触控区域足够大。
  - 用户反馈：

- [ ] **7. 外部编辑器同步**
  - 操作：在 VS Code 或 Obsidian 中打开 `data/vault`（开发模式为 `data-dev/vault`），修改当前在 Lode 中打开的笔记并保存；再在 Lode 有未保存修改时重复一次。
  - 预期：没有本地修改时约 1–2 秒内正文自动更新，光标位置保留；有本地修改时顶部出现"这篇笔记已在别处被修改，你的修改尚未保存。"提示条，本地修改不会被覆盖；点"载入最新版本"后显示外部内容（本地未保存的修改会丢弃）。
  - 注：阶段 2 起行为变化。有本地修改时不再出现提示条，Lode 立即保存并由服务器三方合并；改了同一处时 Lode 的版本另存为冲突副本。按阶段 2 构建验收时，以 `docs/checklist/stage-2.md` 第 8 项为准。
  - 用户反馈：

- [ ] **8. 快捷键**
  - 操作：分别按 Ctrl+K、Ctrl+\、Ctrl+Shift+F、Ctrl+Alt+N、Ctrl+S。
  - 预期：依次打开快速切换、收起/展开侧栏、切到搜索、新建笔记（光标进入标题）、立即保存。
  - 用户反馈：

- [ ] **9. 深色模式与主题切换**
  - 操作：点侧栏底部的主题按钮循环切换"跟随系统 / 浅色 / 深色"；再修改系统主题。
  - 预期：切换即时生效，刷新后保持；跟随系统时随系统主题变化；所有面板、菜单、对话框配色一致，文字对比度足够。
  - 用户反馈：
