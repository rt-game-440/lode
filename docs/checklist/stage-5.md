# 阶段 5 人工验收清单

准备：

- 生成主密钥并设置环境变量，然后构建运行：

  ```bash
  export LODE_SECRET_KEY="$(openssl rand -base64 32)"   # PowerShell：$env:LODE_SECRET_KEY = '<一串随机字符>'
  scripts/build.sh && bin/lode serve
  ```

  主密钥要长期保存：换了主密钥，已保存的 API key 就解不开了，需要重新填写。
- 准备至少两家供应商的 API key（OpenAI 兼容、Anthropic、Gemini 任选两家；OpenRouter、DeepSeek 等选“OpenAI 兼容”）。key 只填进 Lode 的设置页，不要贴到别处。
- 手机验收需要按 [docs/dev-https.md](../dev-https.md) 配好局域网 HTTPS。

- [x] **1. 配置两家供应商并测试连接**
  - 操作：
    1. 设置 → 助手 → 添加供应商，填名称、选接口类型、粘贴 API key，保存。
    2. 点“测试连接”，在列表里点一个模型，核对上下文窗口和最大输出后保存。对支持思考的模型勾上“推理”，对支持图片的模型勾上“图片”。
    3. 用同样的方法添加第二家供应商。
  - 预期：
    - 测试连接显示“连接正常，找到 N 个模型”；故意填错 key 时显示“API key 无效或没有权限”。
    - 保存后只显示 `key ••••末4位`，重新打开编辑框也看不到完整 key。
  - 用户反馈：通过（2026-11-08）

- [x] **2. 日常对话、@ 笔记和工具调用**
  - 操作：
    1. 打开一篇笔记，点编辑器右上角或侧栏底部的 ✨（助手）。
    2. 问一个需要搜索的问题，例如“我哪些笔记提到了 XXX？总结一下”。
    3. 输入 `@` 附上另一篇笔记再提问。
  - 预期：
    - 回复逐字流式出现，有搜索、读取等工具卡片，点开能看到参数和结果。
    - 右上角的用量（如 `3.2k / 128k`）随对话增长。
    - 刷新页面后对话还在，“全部对话”里能切换和删除对话。
  - 用户反馈：通过（2026-11-08）

- [x] **3. 推理强度和切换模型**
  - 操作：
    1. 选一个开了“推理”的模型，把输入框下方的推理强度切到“高”，问一道需要推理的题。
    2. 同一对话中把模型切换到另一家供应商的模型，继续追问。
  - 预期：
    - 推理模型的回复上方有可展开的“思考过程”（供应商不返回思考内容时没有这一项）。
    - 切换模型后继续对话不报错，上下文能接上。
  - 用户反馈：通过（2026-11-08）

- [x] **4. 图片输入**
  - 操作：
    1. 选一个勾选了“图片”的模型，点回形针 → “从设备选择…”上传一张截图；再试“笔记库里的图片…”。
    2. 让助手描述图片内容。
    3. 切到没有勾选“图片”的模型。
  - 预期：
    - 能正确描述图片；用户消息上方显示附件名。
    - 不支持图片的模型上，回形针按钮变灰，悬停提示原因。
  - 用户反馈：通过（2026-11-08）

- [x] **5. 写入批准**
  - 操作：
    1. 让助手修改当前笔记，例如“在末尾加一个今天的待办清单”。
    2. 看审批卡片里的差异，点“拒绝”；再让它改一次，点“批准”。
    3. 让它“新建一篇笔记记录今天的会议要点”，再让它“把这篇笔记移动到 归档/ 下”，最后“删除这篇笔记”。
  - 预期：
    - 拒绝后笔记不变，助手知道被拒绝了；批准后编辑器内容立刻变化，不需要刷新。
    - 新建、移动、删除各自弹出审批卡片；删除的笔记出现在回收站，可以恢复。
    - 在另一台设备（或另一个标签页）打开同一篇笔记，也能实时看到修改。
  - 用户反馈：通过（2026-11-08）

- [x] **6. 手机上的助手**
  - 操作：手机打开 Lode，进入一篇笔记，点右上角 ✨；对话一轮后点左上角返回。
  - 预期：助手是全屏页面，输入法弹出时输入框不被挡住；当前笔记默认附上；返回后回到笔记列表。
  - 用户反馈：通过（2026-11-08）
