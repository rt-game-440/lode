# 阶段 3 人工验收清单

准备：

- 真机测试需要 HTTPS，按 [docs/dev-https.md](../dev-https.md) 配好 Caddy 和根证书。
- 用构建好的二进制：`scripts/build.sh` 后运行 `bin/lode serve`。
- 手机指宽度小于 768px 的竖屏；平板指 iPad 等 768–1100px 的设备。

- [x] **1. 左缘返回手势的跟手感（iOS Safari 和 Android Chrome 各一次）**
  - 操作：
    1. 在文件树里打开一篇笔记。
    2. 手指从屏幕最左缘按下，慢慢向右拖到屏幕中间，不松手，左右来回移动几次。
    3. 拖到约 1/4 处松手。
    4. 再从左缘快速向右轻扫一下（距离很短但速度快）。
  - 预期：
    - 拖动时笔记页紧贴手指移动，下层的文件树同时略微右移、遮罩逐渐变淡，没有延迟或跳动。
    - 来回移动时页面始终跟着手指，不会自己弹走。
    - 慢拖到 1/4 处松手会弹回笔记页；快速轻扫即使距离短也会返回文件树。
    - 上下滚动正文时不会误触发返回。
    - iOS Safari 自带的“边缘右滑后退”可能与之同时出现，请记录实际表现（PWA 主屏模式下没有系统后退手势）。
  - 用户反馈：通过（2026-11-08）

- [x] **2. 右栏抽屉的跟手感**
  - 操作：
    1. 在笔记页点顶栏右侧的“显示右栏”按钮（手机或平板）。
    2. 按住抽屉向右慢拖一小段后松手；再按住抽屉向右快速甩出。
    3. 打开抽屉后，在抽屉里的“反链”列表上下滚动。
  - 预期：
    - 抽屉从右侧滑入，遮罩淡入。
    - 拖动时抽屉 1:1 跟手，遮罩随拖动距离变淡；向左拖超过打开位置时有阻力感（橡皮筋），不会硬停。
    - 小幅慢拖松手弹回；快速甩出则关闭，出去的方向和进来的方向一致。
    - 抽屉内能正常上下滚动，滚动时抽屉不左右晃。
  - 用户反馈：通过（2026-11-08）

- [x] **3. 软键盘弹出时的遮挡与编辑工具栏**
  - 操作：
    1. 在手机上打开一篇较长的笔记，点正文靠下的位置开始输入，让软键盘弹出。
    2. 观察工具栏，依次点“标题”“列表”“任务”“链接”“笔记链接”。
    3. 点“图片”，从相册选一张图片。
    4. 点工具栏最右边的“收起键盘”。
  - 预期：
    - 键盘弹出后，工具栏贴在键盘上方，光标所在行没有被键盘或工具栏挡住。
    - 点工具栏按钮后键盘不收起，对应的 Markdown 插入到光标处；“笔记链接”插入 `[[]]` 并弹出补全列表。
    - 选完图片后正文出现 `![[...]]` 并显示图片；取消选择时工具栏不残留。
    - 收起键盘后工具栏滑出消失，整个页面恢复全高，没有空白条。
    - 刘海屏、底部横条区域的内容都没有被遮挡（安全区）。
  - 用户反馈：通过（2026-11-08）

- [x] **4. 整体观感是否像 Apple 原生应用（手机 + 电脑，亮/暗各看一遍）**
  - 操作：
    1. 电脑上：按 `Ctrl+\` 收起、展开侧栏，在动画进行中再按一次；拖侧栏右边缘调宽后刷新；按 `Ctrl+K` 打开快速切换器；按 `?` 打开快捷键一览；编辑一段文字看顶栏的保存状态；删除一篇笔记后到回收站恢复。
    2. 手机上：浏览文件树、打开笔记、返回、打开设置。
    3. 系统设置里切换深色模式，以及（可选）打开“减弱动态效果”“降低透明度”“增强对比度”。
  - 预期：
    - 动画都是不过冲的平滑弹簧，动画中途反向时从当前位置转向，不跳回起点。
    - 侧栏、顶栏、菜单、快速切换器有毛玻璃质感，能隐约看到下方内容。
    - 按钮按下时立即有轻微缩小；只在用键盘操作时出现蓝色焦点环。
    - 侧栏宽度刷新后保持。
    - 减弱动态效果时，侧栏和切换器不再滑动或缩放，只淡入淡出；降低透明度、增强对比度时毛玻璃变为实色。
    - 整体字体、间距、圆角、颜色像 macOS / iOS 自带应用。请写下最不像的 1–3 处。
  - 用户反馈：通过（2026-11-08）

- [x] **5. 大量笔记时的文件树（可选）**
  - 操作：
    1. `cd server && go run ./cmd/gennotes -dir <vault目录> -n 3000` 生成测试笔记，打开 Lode。
    2. 快速滚动文件树，用方向键从头走到几十行之后。
  - 预期：滚动流畅，没有空白闪烁；键盘焦点始终在可见区域内。
  - 用户反馈：通过（2026-11-08）
