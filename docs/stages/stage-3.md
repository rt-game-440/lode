# 阶段 3/6：Apple 风格与移动端打磨

依赖：阶段 2（#2）。开始前按 `AGENTS.md` 的"开始一个阶段"执行，共同约定见 `docs/SPEC.md`。分支名 `stage-3-design`。

目标：把已有界面打磨到接近 Apple 原生应用的观感和手感，并让手机上的体验完整可用。本阶段只改表现层和交互，不加笔记功能（下文列出的快捷键一览、侧栏调宽等交互改进属于本阶段范围）。动手前先加载 `apple-design` skill，全程以它为准；动效细节可同时参考 `animate`、`review-animations` skill。

## 范围内

### 设计规范

- 写 `docs/design.md`：字体层级、间距栅格、颜色（亮/暗，含强调色）、材质、圆角、阴影、图标、弹簧参数、各类反馈的规则。
- `web/src/styles/tokens` 是唯一来源：组件里不出现硬编码的颜色值和动画时长，统一引用 tokens。
- 材质：侧栏、工具栏、弹出层用半透明毛玻璃（`backdrop-filter`），不支持时用实色兜底。
- 字体和图标遵守 SPEC 的许可证限制（系统字体栈、开源图标）。

### 动效与反馈

- 统一的弹簧参数用于：面板切换、侧栏展开收起、列表增删、快速切换器弹出、toast、保存状态变化。
- 动画可中断：手势或动画进行中反向操作时，从当前位置平滑转向，不跳变。
- 只对 transform 和 opacity 做动画。
- 按压反馈（约缩放到 0.97）、hover、仅键盘操作时显示的 focus ring。
- `prefers-reduced-motion` 时位移和缩放动画改为淡入淡出或直接切换。

### 移动端（宽度 < 768px）

- 单栏导航栈：文件树 → 笔记，从屏幕左缘右滑返回，跟手移动，松手按速度和位置决定完成或取消。
- 侧栏抽屉同样跟手拖拽。
- 编辑时底部工具栏提供常用 Markdown 插入（标题、列表、任务、链接、`[[`、图片）。
- 虚拟键盘弹出时编辑器光标和工具栏不被遮挡（用 `visualViewport`）。
- 适配安全区 `env(safe-area-inset-*)`；可点区域 ≥ 44px。

### 平板与桌面

- 侧栏可拖拽调宽、可收起，宽度记住。
- 按 `?` 打开快捷键一览。
- 文件树超过约 2000 项时虚拟滚动。

### 无障碍

文字对比度达到 WCAG AA；语义化标签和 ARIA；所有功能可只用键盘完成。

## 范围外

新的笔记功能、同步协议、后端改动（为界面需要的极小接口除外，须在 PR 中说明）。

## 集成约定

阶段 5 的 Agent 面板直接复用本阶段的 tokens、面板组件和动效，所以面板、弹层、列表、toast 要做成可复用组件。

## 保持不变

所有功能行为不变；已有测试继续通过。选择器因改版需要更新时同步修改测试，覆盖范围不减少。

## 验收标准

1. `docs/design.md` 存在；用 grep 或 lint 规则检查组件中没有硬编码颜色值和动画时长。
2. Playwright + axe-core 扫描首启、登录、主界面、设置页，无 serious / critical 级问题。
3. Playwright 在 reduced-motion 模式下检查侧栏和快速切换器没有位移动画。
4. Playwright 在 375、768、1440 三种宽度下检查各页面无横向滚动、无元素重叠。
5. 3 级：各页面 × 亮/暗 × 桌面/手机截图，以及侧栏抽屉拖拽、返回手势、快速切换器、保存反馈的录屏。先用 `frame-inspect` 自查卡顿、跳帧和闪烁，再推送。
6. 写入 `docs/checklist/stage-3.md`：真机上返回手势和抽屉的跟手感、键盘弹出时的遮挡、整体是否像 Apple 原生应用。
